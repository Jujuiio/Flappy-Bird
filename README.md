# PA0: Flappy Bird (Pygame)

Recreación sencilla del clásico juego **Flappy Bird** desarrollada en Python usando la librería **Pygame**. Este proyecto forma parte de la asignación introductoria PA0 para ajustar mecánicas básicas de juego como física, colisiones y puntuación.

---

##  Requisitos Previos

Antes de ejecutar el juego, asegúrate de tener instalado:

* **Python 3.x**
* **Pygame**: Puedes instalarlo ejecutando el siguiente comando en tu terminal:
  
  pip install pygame
